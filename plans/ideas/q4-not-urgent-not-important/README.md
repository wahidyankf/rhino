# Q4 — Neither Urgent nor Important

Ideas deliberately parked. Writing one down is not a commitment to do it; it is a way of stopping the same suggestion
from being rediscovered and re-argued every few months. An idea with no evidence for urgency or impact belongs here
until it has some.

Add one kebab-case Markdown file per idea, in the shape [the index](../README.md) describes.

## Directory Map

- [Empty pre-push update records](empty-pre-push-update-records.md) proposes telling a push that publishes nothing,
