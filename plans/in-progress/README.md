# In Progress

This stage holds only plans being executed right now. Keep each plan's status, its `delivery.md` checklist, and its `learnings.md` log synchronized with what has actually happened. A checklist that is accurate only at the end was never a checklist.

Work starts by moving one folder from [`../backlogs/`](../backlogs/README.md) without renaming it, and follows [plan execution](../../repo-governance/workflows/plan-execution.md).

Work completes only after every required outcome, acceptance condition, verification, learning, and triggered conditional task is reconciled against the record. A dormant recovery task is given a dated, evidenced `Not triggered` disposition rather than a checkmark. Then the same workflow performs the collision-refusing dated move into [`../done/`](../done/README.md), with both stage indexes updated in that one change.
