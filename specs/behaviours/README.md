# Stable Behaviours

The stable corpus is one grouped-v2 contract. Every scenario binds at the unit,
integration, and E2E boundary. It declares only policy owned by
`rhino/repo-config/v2`; predecessor schemas survive only as rejection fixtures.

- [v0-4-contract.feature](v0-4-contract.feature) — configuration, policy,
  lifecycle, harness, environment, toolchain, and stable predecessor-rejection
  contracts.
