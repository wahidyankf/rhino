# Language

Write every repository-owned artifact in English: documentation, specifications, code comments, identifiers, commit messages, pull-request bodies, and validator output.

This repository is public and its consumers are not known in advance. English is the language its dependencies, its toolchain, and its issue tracker already use, so a second language in one corner would be a barrier rather than an accommodation.

Use plain English. Prefer the shorter word, expand an abbreviation on first use, and do not assume the reader shares this repository's history.
