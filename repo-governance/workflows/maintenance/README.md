# Maintenance Workflows

Upkeep and delivery: what keeps the repository clean, lean, released, and integrated.

## Directory Map

- [Dev artifact clean-up](dev-artifact-clean-up.md) — removing the artifacts one piece of work created, and nothing
  else.
- [Dev artifact clean-up modules](dev-artifact-clean-up/README.md) — other actors' artifacts and bare clones, in reading
  order.
- [Release cut](release-cut.md) — building, checksumming, and tagging a release that can never be replaced.
- [Rules grooming](rules-grooming.md) — a sweep for volume carrying no obligation. Never writes.
- [Worktree to pull request](worktree-to-pull-request.md) — the only path from a change to `main`.
